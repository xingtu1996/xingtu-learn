# 模板

开新学习线时，复制这里的文件，改个名字就能用。

| 模板 | 用途 |
|------|------|
| [`学习线模板.md`](学习线模板.md) | 一条学习线的 README 骨架（含学习目标 / 进度 / 复盘 / 下一步） |
| [`周日志模板.md`](周日志模板.md) | 每周记录：学了什么 / 产出什么 / 卡在哪 / 下周计划 |

---

## 使用方式

```bash
# 复制模板到新学习线
mkdir -p 10-tech/<新主题>
cp templates/学习线模板.md 10-tech/<新主题>/README.md

# 每周日志
cp templates/周日志模板.md 30-log/2026-WXX.md
```

## 三条填写纪律

1. **「读者能拿走什么」这一行必须填**。答不上来，说明这条线还没想清楚，先别开。
2. **学习目标必须可验证**——能演示、能跑、能讲给外人听。「我理解了」不算。
3. **status 字段必填**，且过时了要改、不要删（见 [方法卡 03](../00-method/cards/card-03-给笔记打时间戳与成熟度.md)）。
