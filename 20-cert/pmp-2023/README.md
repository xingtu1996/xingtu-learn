## 关于这条线的可信度

这条线是**回溯型**的——2023 年备考时我没有做公开记录，现在（2026-09）依靠本地文件时间戳和回忆重建。

所以：

- **时间线**：以本地文件的创建/修改时间为准，可信度较高
- **方法与感受**：记忆重建，可能与当时实际有出入
- **考试结果**：`[待本人确认]`，暂时不写死

诚实说明这一点，是因为这个仓库的价值建立在「记录可信」上。记忆会自我美化，我能做的是把不确定的地方标出来。

## 这条线放什么、不放什么

**放**：我自己的备考节奏、方法、踩坑、复盘。

**不放**（红线）：

- 培训机构讲义（PDF / DOCX）——机构版权，不进公开仓库
- PMI 申请报告原件——含个人身份信息
- 任何题库与真题

**这里能公开的，只有属于我自己的那部分**：方法、节奏、判断。而这部分恰恰是别人真正想看的——讲义谁都能买，方法买不到。
