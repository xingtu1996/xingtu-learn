## 为什么开这条线

2023 年拿证时只记了「怎么考」（见 [`../pmp-2023/`](../pmp-2023/)），没记「拿证之后怎么保住」。三年后周期收尾，网上流传一份「60 个 PDU 免费保姆级教程」，照着点 12 步就能凑满——看起来是纯操作题，实际上是一道规则题。

这条线记的不是「我续证成功了吗」，而是**在一个只有几周窗口、且无法回滚的场景里，怎么把一份二手教程拆成可验证的事实**。这类能力换到任何认证、任何合规流程都还能用。

## 学习目标（可验证）

| 阶段 | 学完能做什么 | 状态 |
|------|--------------|------|
| 1 | 能把一份教程拆成「路径 / 数量口径 / 声明义务 / 隐藏成本」四层，逐层给出官方出处 | 已完成 |
| 2 | 能说清 PMP 续证的结构约束（60 / 35 / 25 / 8-8-8 / 1 小时 = 1 PDU）并指出教程里的冲突点 | 已完成 |
| 3 | 能回答「过期之后还能不能续证」，并说清暂停期的边界与代价 | 已完成 |
| 4 | 能把结论变成可执行的申报与留档清单，且在 CCRS 里核对过真实缺口 | **未开始**（需登录，属个人操作，不在公开仓记录） |

## 当前进度

规则核验与决策记录已落盘；CCRS 的真实缺口已取数（**0 Applied / 60 Remaining**，状态正常，2026-11-05 核对）。但**实际申报与缴费未执行**——诚实标在这里：这是一条「判断完成、数据已核、执行未开始」的线，不是成功复盘。

一个值得记的口径：0 Applied 说的是「三年里一条都没申报」，不是「一条都没做过」。60 PDU 是周期累计，不是最后 28 天要新做 60 小时；把周期内真实发生过的活动按实际小时补报即可。焦虑往往来自把「累计值」误读成「剩余待办」。
