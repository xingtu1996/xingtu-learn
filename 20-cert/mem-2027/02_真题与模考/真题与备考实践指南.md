## 一、真题资产盘点（16年 × 2科，全部免费可得）

管理类联考（199管综+204英语二）自 2010 年开考，至 2025 年共 **16 年真题**。

| 年份段 | 用途定位 | 什么时候用 |
|---|---|---|
| 2010-2019（10年） | **日常练习弹药库**：拆章刷题、英语阅读每日1篇的来源 | W1-W8 每天 |
| 2020-2022（3年） | 补充模拟/弱项专项 | W8-W11 机动 |
| **2023** | **摸底基线**（已用于9.28）→ W5 二刷 | W1/W5 |
| **2024** | W4 阶段验收 → W6 二刷 | W4/W6 |
| **2025** | 全真模考①（11.8）→ W7 二刷 | W7 |

### 免费获取渠道（不用买、不碰盗版）

| 渠道 | 内容 | 用法 |
|---|---|---|
| **MBA大师 App** | 近20年 5000+ 真题，文字解析，拍照搜题 | 通勤刷题主力；错题自动进错题本 |
| **海绵MBA App** | 真题套卷（按年份/科目），**每题配视频解析**，自动判分 | 周末整块时间的套卷训练 |

> 英语二阅读每日1篇 = 从 2010 年起顺序做，88天刚好覆盖 16 年 64 篇阅读中的精华部分；做一篇少一篇，**不浪费真题**是基本原则（模拟题不替代真题）。

## 三、「考证状态」就绪清单（Definition of Done）

进考场前逐项打勾，全部✅才叫"达到考证状态"：

### 分数就绪
- [ ] 最近2次全真模考总分 ≥165（目标168留3分余量）
- [ ] 英语二模考 ≥42（红线39留3分余量）
- [ ] 管综模考 ≥85（红线78留余量）

### 能力就绪
- [ ] 三年真题（2023/2024/2025）三刷完成，错题本二刷完成
- [ ] 答题顺序固定：管综=逻辑→小作文→大作文→数学；英语=阅读A→作文→新题型→翻译→完型
- [ ] 论证有效性分析 25 分钟内成文，找4个漏洞的模板能默写
- [ ] 英语大小作文模板能默写，无卡顿
- [ ] 涂卡节奏演练过≥3次（每模块做完即涂）

### 事务就绪
- [ ] 网上确认通过（11月上旬）
- [ ] 准考证打印×3（12.9起）
- [ ] 考试物品：身份证+准考证+2B铅笔+黑色签字笔+手表（非智能）
- [ ] 考点路线踩点，早起闹钟×2

## 四、与计划的挂接（不新增负担）

本指南不改变逐日计划，只是把"每天练什么题"的**来源**钉死：
- 数学/逻辑每日10-15题 → 对应章节的老吕母题800练 + MBA大师章节练习
- 英语阅读每日1篇 → 2010年起顺序做早年真题（W5起切换为当年真题精读）
- 写作 → W4起按周写，用 `ai-playbook/prompts.md` 模板2 批改
