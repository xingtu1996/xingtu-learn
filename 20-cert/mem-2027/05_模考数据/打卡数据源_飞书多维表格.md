## 统一数据 Schema（两边字段对齐）

| 字段 | 说明 | 示例 |
|---|---|---|
| date | 日期 | 2026-09-29 |
| planned_task | 计划任务（来自逐日总览） | 数学·代数·整式+10题 |
| actual_minutes | 实际学习时长 | 90 |
| subjects | 实际完成科目 | 数学/英语单词 |
| completion | 完成度 | 100% |
| momo_words | 墨墨当日新词 | 50 |
| note | 备注/卡点 | 整式第3节例题卡了 |

## 合并规则

1. **checkin/ 周表 = 唯一权威记录**；飞书表是采集端，每周合并一次，以飞书时长为准、checkin 备注为补充。
2. 两边冲突时以飞书实际记录为准，在周报"差异说明"节标注。
3. 监控 KPI（SPI-lite/学习强度）由合并后的 checkin 数据计算。
