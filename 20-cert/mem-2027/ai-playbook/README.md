# AI 备考 Playbook · 北邮MEM 88天

> 这份文件记录：一个在职、英语薄弱、技术人背景的考生，怎么用AI把备考效率拉满。
> 每用一个有效玩法，就往这里加一条。考完就是开源作品。

---

## 铁律（边界，不能破）

1. **先做再问**——AI是事后对照工具，不是替你思考。拍照直接问"选什么"=白学
2. **错题先自己想一遍为什么错**，再让AI拆解。想不出来也没关系，但要试过
3. **不依赖AI做选择题**——考场上没AI。用AI是为了搞懂，不是为了对答案
4. **所有产出（错题分析、作文批改）落档**——不复盘的学习等于没学

## 场景地图（什么时候用AI干什么）

| 场景 | 做什么 | 频率 |
|------|--------|------|
| 错题复盘 | 拍照/输入错题，AI拆解考点+同类题解法 | 每天 |
| 英语作文 | 写完发给AI按阅卷标准批改 | 每周2篇 |
| 长难句 | 自己拆完不确定的句子，AI对照 | 阅读精读时 |
| 模考分析 | 报分数+错题，AI分析强弱项+调整建议 | 每次模考 |
| 周计划 | 每周日AI根据打卡数据给下周建议 | 每周 |
| 背单词 | 不用AI，墨墨APP搞定 | 每天 |

## 对话协议（怎么跟AI说最高效）

**不用客气，直接甩。** 格式越随意越好，AI负责理解。

### 日常打卡
> "今天背了50个单词，做了10道数学题，学了2小时，卡在逻辑假言命题"

AI自动拆成：日期/科目/时长/卡点，写入打卡表。

### 错题拆解
> "这道题我选B答案选C，管综数学，考点是什么？这类题通用解法？"

### 作文批改
> "帮我批改这篇英语二作文，按考研英语二阅卷标准打分，指出语法错误+更好的替换词。[贴作文]"

### 模考复盘
> "刚做完2025真题，英语55管综90总分145，帮我分析：差在哪？下一步重点？"

## PDCA闭环（每天/每周怎么跑）

### Plan（规划）——我来做
- 三阶段计划：plan.md
- 每周日：我根据打卡数据排下周日程
- 启动时：第1周逐日安排已排好

### Do（执行）——你来做
- 每天打开墨墨背单词（最低保底10分钟）
- 按本周课表学数学/逻辑/阅读
- 学完在飞书表单打卡，或直接跟我说"今天学了XX"

### Check（监控）——数据自动跑
看板自动统计，红线触发我主动提醒：

| 监控指标 | 绿灯（正常） | 黄灯（要注意） | 红灯（我会找你） |
|---------|------------|--------------|----------------|
| 连续打卡 | ≥5天 | 断1天 | 连续断2天 |
| 日均学习时长 | ≥2h | 1-2h | <1h连续3天 |
| 模考总分 | 逐次上升 | 持平 | 连续2次下降 |
| 英语单词 | 墨墨连续打卡 | 漏1天 | 连续3天没打开 |

### Act（收尾/复盘）——每周日
每周日我做三件事：
1. 读你这周的打卡数据
2. 判断：进度跟计划差多少？哪科拖后腿？
3. 给下周调整建议+新的逐日课表
