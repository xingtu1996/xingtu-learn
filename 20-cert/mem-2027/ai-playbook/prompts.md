# 可复制提示词模板库

> 每个场景一段模板，复制即用。备考过程中不断补充。

---

## 1. 错题拆解

```
你是管综阅卷老师，满分要求拆解这道题。

我的答案：X
正确答案：Y
科目：[数学/逻辑]

请告诉我：
1. 这道题考的核心知识点是什么？
2. 我的错误属于哪类（知识点盲区/审题失误/计算错误/时间不够）？
3. 这类题的通用解题步骤是什么？
4. 下次遇到类似题，第一反应应该看什么特征？
```

---

## 2. 英语作文批改

```
你是考研英语二阅卷老师，按实际评分标准批改。

[贴作文]

请按以下结构输出：
1. 总分（满分15分/小作文10分）+ 一句话评价
2. 逐句标出语法错误，给出修改版
3. 哪3个词/短语可以替换成更地道的表达
4. 逻辑结构问题：段落之间顺不顺？
5. 修改后的高分版本（保留我的原意）
```

---

## 3. 长难句对照

```
我在拆这句英语阅读长难句，请对照我的分析帮我看漏了什么。

原句：[贴句子]
我的拆分：[写你找的主干和从句]

请告诉我：
1. 我的主干找对了吗？
2. 有没有漏掉的从句或修饰成分？
3. 这句话在考试里最可能的考点是什么（指代/倒装/省略）？
```

---

## 4. 模考复盘

```
刚做完[年份]真题，分数如下：
英语二：X/100
管综：Y/200
总分：Z/300

我的目标：英语≥39 管综≥78 总分≥168

请帮我分析：
1. 现在离目标差多少？
2. 哪个科目是当前最大短板？
3. 接下来一周最该做什么？
4. 有没有可以放弃的内容（时间不够的话）？
```

---

## 5. 周计划生成

```
本周打卡数据：
- 学习总时长：X小时
- 完成了哪些科目：
- 模考分数（如有）：
- 本周卡点：

当前阶段：[基础打底/真题强化/冲刺模考]
距考试还有：X天

请给下周计划：
1. 每天重点科目安排
2. 本周要完成的核心任务（3件以内）
3. 什么情况说明计划要调整
```
