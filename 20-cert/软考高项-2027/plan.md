## 一、考试结构（先认清楚，3 科一次全过）

| 科目 | 题型 | 及格线 | 特点 |
|------|------|:---:|------|
| **综合知识** | 75 单选（含 5 道专业英语） | 45/75 | 项目管理 60% + IT 技术 20% + 运筹计算 5-10% + 法规 5%；5 道英语题**策略放弃**（英语弱，每科容错 30 分，不差这 5 道） |
| **案例分析** | 3 道大题（挣值计算 + 关键路径 + 情景简答） | 45/75 | **计算题必考且模板化**，是拿分主战场 |
| **论文** | 机打 2500-3000 字 | 45/75 | 结合真实项目，套模板查重不过；**80% 挂科点** |

> 铁律：三科同一次考试全过才有效，单科成绩不保留不滚动，挂一科全重来。
> 机考：全程打字，论文 120 分钟内 2500 字 ≈ 需 ≥40 字/分钟，考前练。

## 四、记忆系统（化解"背了忘"焦虑）

1. **不突击，靠间隔重复**：工作日每天 15 分钟刷记忆卡（Anki 或自制），旧卡优先于新卡——遗忘曲线靠重复对抗，不靠一次性背完。
2. **框架挂载**：一切知识点先问"这在 5×10 矩阵的哪个格子"，答不出就查图，不背孤立清单。
3. **错题本即复习本**：只记错题+错因，每周日回滚上周全部错题，月底回滚整月。
4. **计算题是肌肉记忆**：公式反复套用 20 道以上自然记住，不需要"背"。
5. **遗忘是正常的**：忘≠没学，复习一次比初学一次省力 80%。8 个月周期下，同一知识点会自然碰到 5-8 次。

## 五、材料清单 + 公式卡（考前只背这个）

**必买**：
- 《信息系统项目管理师教程（第4版）》（官方指定教材）
- 近 5 年真题集（2019-2024，含综合+案例+论文范文）
- XMind（免费版，画矩阵图）

**自建公式卡**（考前冲刺只看它）：

```
挣值（必考）：
  PV 计划价值  EV 挣值    AC 实际成本
  SV = EV - PV      （>0 进度超前）
  CV = EV - AC      （>0 成本节约）
  SPI = EV / PV     （>1 进度超前）
  CPI = EV / AC     （>1 成本节约）
  完工估算 EAC = BAC / CPI；完工尚需 ETC = EAC - AC

网络图/关键路径：
  最早 ES/EF = 顺推取大；最迟 LS/LF = 逆推取小
  总浮动 = LS - ES = LF - EF；关键路径 = 浮动 0 的路径
```

## 七、长线学习调整（用户已学部分 + 防断档）

### 7.1 长线是正确答案
突击 3 个月易断易忘；长线 8 个月每天 25-60 分钟，同一知识点自然重复 5-8 次。
**难的不是学，是不断**——本计划一切机制围绕"不断"设计。

### 7.2 已学部分处理（PMP 底子：2023-12 通过 PMP® #3712260）
**PMP 覆盖 ✅**：PMBOK 6/7 版 + 乐凯讲义 + 思维导图（启动/执行/监控/收尾）→ 十大管理领域、挣值、生命周期已内化
**高项新增 ❌（4 个独立新体系，从头学，不是补丁）**：
> 用户定性（2026-08-20）：这 4 块是不同体系，需重新学起——学习本身也是开阔眼界，应试只是副产品。
> 体系价值：①中国化=体制内项目语言（回国进国企/事业单位敲门砖）②计算=排期硬技能（从"感觉"到"算出来"）③IT 全景=技术地图系统化+合规红线 ④论文=经验资产化（顺带内容素材）
1. **中国化内容**：立项/可研论证、招标投标、政府采购、监理、法规/国标（PMP 完全没有）
2. **论文**：机打 2500-3000 字结合真实项目（PMP 全客观题）——最大新增量
3. **计算题硬化**：关键路径/网络图/三点估算（PMP 有挣值但高项更数学）
4. **IT 技术 + 法规**：综合知识 25%（PMP 不考技术）

**处理**：管理领域用真题验证跳过（目标选择 ≥50-60 分）→ 只精读补差 4 块 → 基础期 16 周压到 4-6 周。
**PMP 续证 ⚠️（2026-12-03 到期，剩 ~3.5 个月）**：需 60 PDU + 续证费（非会员约 $150，以 PMI 官网为准）。走国内人才引进 → **软考高项 > PMP**，PMP 仅外企/投标加分时值得续；不续则省时间给高项。

### 7.3 防断档机制（上次断档的根因对策）
| 机制 | 做法 |
|------|------|
| 最小承诺 | 每天 **25 分钟**起步，超额算赚——降低"今天太累算了"的启动门槛 |
| 固定锚点 | 绑定通勤/午休/睡前固定时段，**不靠意志力找时间** |
| 打卡可视化 | 每周勾打卡表（`06_软考高项_每周打卡模板.md`），看得见进度就不会停 |
| 断档兜底 | 断 1 周可补；断 1 月回滚错题再继续——**中断 ≠ 放弃**，绝不因断档推翻整个计划 |
| 里程碑奖励 | 每阶段完成给个小奖励 |
| 备考搭子（可选） | 加软考备考群 / 找个同伴互相打卡 |
| 工具固定 | Anki 每天自动复习 15 分钟；XMind 矩阵图每周更新一次 |
