## 与教程 skill 的唯一分工差异（先说清）

教程 skill 的前提是「AI 的浏览器跑在用户自己的设备与网络上」（其列举的 Grok Bot、ChatGPT 等均为本地形态）。Muse 的浏览器跑在云端、出口为海外 IP，与中国资料组合是实测的典型被拒形态。因此本执行单把分工调整为：**页面在用户手机/Mac 上打开（本人网络），Muse 实时陪跑**——每步报下一步、核对页面状态、读报错排障；密码、卡号、验证码永不经聊天，由用户在页面亲手填。其余规则（资料真实、一人一号、不多开、不绕风控）与教程 skill 完全一致。

## 开工前收集（不涉及敏感值）

1. 注册邮箱：能正常收信；一个邮箱只能注册一个账号，也是日后登录名。
2. 实体卡有无：Visa / Mastercard / Amex 信用卡，或带卡组织标志且无需 PIN 的借记卡。虚拟卡、预付卡、一次性卡直接出局——这是唯一硬门槛，只确认有无，不问卡号。
3. 主区域拍板（终身不可改）：避开首尔、东京（A1 容量最紧、页面会弹警告）。候选：大阪（延迟与开通率平衡，本方 v1 推荐）、圣何塞（纯固定 IP 中转用途时开通最稳）、春川、新加坡。

## 执行步骤（10 步，标注执行者）

1. 手机/Mac 开无痕、关 VPN、本人网络，打开 oracle.com/cloud/free → Start for free。Muse 同步进入陪跑。
2. 国家=中国、姓名真实拼音、邮箱。此步即预告第 5 步主区域不可改。
3. hCaptcha 选图验证 → 点 Verify my email → **30 分钟内**去邮箱点验证链接（最常见卡点，动作要快）。
4. 设密码（8–40 位，大小写+数字+特殊符号，不含姓名/邮箱）；账户类型 Individual、云账户名称保持默认并记下来（日后登录租户名）。
5. 主区域按开工前拍板选定，勾不可更改确认 → Continue。
6. 真实地址（与卡账单地址一致）、电话按页面格式、不多加长途前缀 0。
7. Add payment verification method → Credit Card → 填卡号/有效期/CVN → Finish → 等绿勾。可能出现小额临时预授权，几天内自动退回，属正常；不升级套餐不会真扣费。
8. 勾协议 → Start my free trial → 等开通（最多约 15 分钟，邮件通知）。Muse 轮询陪等、判读结果。
9. 点开通邮件 Sign in 登录；首次登录设 MFA：手机装 Oracle Mobile Authenticator（红色图标）扫码绑定——建议开工前先装好。
10. 控制台左上角显示 Free Tier 即完成。**不要点升级。**

## 完成后第一件事

1. 开第一台 A1 实例：按 2 核 / 12G 配置（2026 年现行额度 1500 OCPU 小时 + 9000 GB 小时/月；开 4 核 24G 只能跑约半个月会被停）。抢不到容量换时段重试。
2. 设预算告警（Budget Alert）防误开付费资源被扣费。
3. 用途锚点：固定出口 IP 中转（公众号 API 白名单）、跳板、轻量服务；重要数据不放唯一副本（免费号风控是玄学）。
4. 账号连续 30 天闲置可能被停号/回收，偶尔登录使用。

## 排障速记（教程与实测合并）

- 收不到验证邮件：先查垃圾箱；链接过期（>30 分钟）就回注册页重发。
- 绑卡被拒：先查卡种（虚拟/预付/带 PIN 借记卡必拒）与账单地址一致性；隔一天换时段重试，不连续猛刷。
- 提交后无动静：创建最多约 15 分钟，一直卡住多半是卡或资料问题。
- 容量不足：换时段重试，或等试用期后以 Always Free 身份继续抢；不为抢容量去升级。
