## 先说结论（截至 2026-11-04 的核验口径）

- 「永久免费 4 核 24G」是旧闻：2026 年中起 Always Free ARM 额度减半为 **2 核 / 12G**（1500 OCPU 小时 + 9000 GB 小时/月），另有 2 台 AMD 微实例、200GB 块存储、10TB/月出站。
- 注册的真门槛不是流程而是风控一致性：提交 IP 所在地须与账单地址、手机号、发卡地一致（本例均为中国）；代理/VPN 节点是数据中心共用 IP，为黑名单重灾区，成功案例共识是直连家宽或手机流量注册。
- 主区域（Home Region）与注册 IP 无关，是服务器机房所在地，选定终身不可改。

## VPS 原理与用途笔记

- VPS 是虚拟化切分出的完整虚拟电脑：独立 CPU/内存/硬盘/系统、24 小时运行、配固定公网 IP，远程操控。机场/VPN 节点背后即是他人租用 VPS 加转发程序。
- 「中转」只是用途之一：程序经 VPS 访问目标时，目标只见 VPS 的固定 IP，可解公众号 API 白名单（用户云端出口 IP 轮换、无固定 IP，是本条目的原始动机）。
- 个人站可托管于 VPS，但用户现有站托管在 Cloudflare Pages（免费加速/证书/防护）；分工建议：静态站留 Pages，VPS 承担固定 IP 中转、后端服务、常驻脚本等 Pages 做不了的活。免费机有闲置回收（约 7 天闲置可能回收实例、30 天不登录可能停号）与风控不确定性，重要数据不放唯一副本。
