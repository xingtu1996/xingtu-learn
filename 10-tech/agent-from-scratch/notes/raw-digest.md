# 现场原始要点速记（raw-digest）

这部分是听现场时记下的 raw 条目，还没完全消化成观点。每条标注来源性质：【原句转述】= 讲者意思我重述；【推断】= 我自己的推演；【我此前已知】= 入场前就有的认知。留在这里是为了不丢线索，后续会回流进 01-04 或文章。

## 梁凯锐「点亮第一个 Agent」（14:35-14:59）

- 【原句转述】最朴素的 Agent 就两行：输入拼上下文直接给模型；但模型无工具，答不了执行类任务。
- 【原句转述】五行版多了工具协议+工具集，心脏是「工具结果写回上下文」再二次推理。
- 【原句转述】ReAct 思想源自普林斯顿团队，把「观察—判断—行动—接收」固定成四节点。
- 【原句转述】加 while 循环后，执行工具没变、任务没变，决策权从程序挪到模型。
- 【原句转述】工具协议只要三样：名称、解决什么、输入；不把源码扔上下文。
- 【原句转述】Skill 是 .md 文档，加载进上下文；几百个全放窗口压力大，优化为移出上下文、只留查询入口，省 token。
- 【我此前已知】function calling 基本机制；但「协议即 Harness 最小形态」是现场新接上的。
- 【推断】点→线→圈（对话是点、工具调用+上下文是线、Agent 自主决策是圈）这个图形学联想，和游戏渲染管线的 LOD / 视锥剔除可能同构，待查证。

## 郭美青（百川）HE 六层（14:00-14:12）

- 【原句转述】自底向上六层：任务约束 → 认知 → 决策 → 行动 → 交互表达 → 进化评估。
- 【原句转述】两条线：算法线（效果直接相关）、工程线（可靠性/稳定性/效率）。
- 【原句转述】核心理念：可控 · 可信 · 可进化。
- 【待核实】同模型不同 Harness 效果差 21.8 个百分点这条数据，素材库标了【重建】，未逐字确认，引用前需回看。
