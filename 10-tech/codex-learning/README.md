## 学习循环：输入 → 实践 → 输出 → 复盘

1. **输入**：保存问题、官方文档/版本、截图时间和必要上下文；截图先脱敏。
2. **实践**：写清环境、操作、预期与实际现象；不记录 token、密钥、账号标识或私人路径。
3. **输出**：形成可复用的配置片段、流程、检查项或案例。示例必须可验证且不含秘密。
4. **复盘**：区分事实、观察、假设，记录证据、限制、下次验证方法和更新日期。

学习的关键在“出”：只有能演示、复现、讲清楚的结果，才算从输入变成自己的知识。

## 证据标签

- **已验证事实**：有当前可访问的官方文档、产品界面或可复现实验支撑；注明来源和核验日期。产品会变，及时复核。
- **会话观察**：来自个人截图或实际使用，只描述当时看到的现象，不外推为普遍规律。
- **待验证假设**：解释或估算尚无充分证据；写出验证办法，不当成结论传播。

## 更新纪律

- 每个可变结论写核验日期与来源；无来源就标成观察或假设。
- 不从单张额度截图推导固定消息数，不混淆消息、轮次、会话。
- 公开仓库只保留脱敏、可公开的知识；私人截图和原始对话留在本地私密位置。
- 新案例先写复现条件和验证结果，再蒸馏方法；过期结论改标“已过时”，保留修正轨迹。
