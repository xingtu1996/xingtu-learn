# 用 AI 学东西：我的工具链与陷阱清单

> status: 活跃 ｜ 建立: 2026-09-13 ｜ 实践时长: 约 2 年（2024 起日常使用）
> 读者能拿走什么：AI 当学习搭档的三种具体用法（附可复制提示词）+ 四个必须防的陷阱。

---

## 先定性：AI 是学习搭档，不是答案机

把 AI 当答案机用，你会得到：看起来懂了、实际没懂、还带着三个错误认知离开。

把 AI 当搭档用，它真正的价值在三件事：

1. **压缩检索时间**——把「找资料」从 2 小时压到 10 分钟
2. **提供反例与边界**——这是人类老师都未必肯花时间做的事
3. **当陪练**——出题、追问、挑你逻辑里的洞

第 2 和第 3 才是 AI 相对传统学习的增量。**只会问「这是什么」，是把最贵的部分浪费掉了。**

---

## 三种用法（附提示词）

### 用法一：要骨架，不要细节

学新东西时第一句不要问「XX 是什么」，要问链路。

```
我要学 <主题>。请不要直接讲细节，先给我：
1. 这件事的整体链路分几个阶段，每个阶段解决什么问题
2. 各阶段之间的依赖关系（哪个必须先懂）
3. 一个最小可运行的例子（能跑起来的那种，不要伪代码概念图）
4. 最容易误解的点在哪

讲完链路我再问细节。
```

为什么先要骨架：细节脱离链路就是散沙，记住了也拼不起来。

### 用法二：逼它举反例

理解一个概念最快的方式，是看它在什么情况下不成立。

```
我理解 <概念> 是 <我的理解>。请：
1. 指出我理解里错的部分
2. 给 3 个反例（这个概念不成立或不适用的场景）
3. 如果我的理解只在某个前提下成立，告诉我那个前提是什么
```

这一条我用到最多。**让 AI 挑错，比让它讲解有价值十倍。**

### 用法三：当陪练，让它考你

```
我们正在学 <主题>。请你扮演考官：
1. 出 3 道题，难度递进，覆盖我可能没注意到的边界
2. 我回答后，只说对错，先不给答案——让我再想一次
3. 最后给答案，并指出我思路里的漏洞在哪
```

备考场景（软考高项、PMP）尤其适用。比自己刷题多出来的价值是：它能针对你的错误**连续追问**，这是题库做不到的。

## 四个必须防的陷阱

| 陷阱 | 表现 | 我的对策 |
|------|------|----------|
| **幻觉编造** | 数字、论文、API 签名看着很像真的，实际不存在 | 关键数字和引用**必须二次核实**，笔记里标 `[待核实]` |
| **过度简化** | 把有争议的问题讲成定论，把复杂问题讲成三步法 | 主动问「这个问题有没有不同观点」 |
| **顺着你说** | 你给出错误理解，它不纠正反而帮你圆 | 明确要求「先挑错再补充」，并要求举反例 |
| **时效性** | 训练数据过时，讲的东西半年前就变了 | 新技术一律要求「标注信息截止时间」，并自己查官方文档确认 |

一句话：**AI 给的是待验证的草稿，不是结论。**把它当实习生写的初稿来审，而不是当百科全书来抄。

## 我的实际配置

诚实说明，供参考而非推荐：

- **日常主力**：Claude Code CLI（终端 agent，边学边跑代码，学习闭环最短）
- **备考与长文**：能处理长上下文的通用助手（用于整理、追问、出题）
- **检索**：官方文档优先，AI 只负责加速定位，不负责给结论
- **沉淀**：学完立刻让 AI 帮我整理成结构化笔记，但**观点和判断必须我自己写**——这一步不能外包，外包了就等于没学
