## 这不是什么

这不是「我的学习笔记」。GitHub 上 99% 的学习仓库活不过 30 天，原因不是主人不够努力，而是它们只回答了「我学了什么」，没回答**「你为什么要看」**。前者是日记，后者才是作品。

所以这个仓有一条生死线：

> **每一条记录，都必须让陌生人拿走一样能用的东西**——一个模板、一条路径、一条踩坑结论、一段可复制的提示词。

学习过程是这些东西的出厂证明，不是它本身。

## 它是什么：过程态资产

行途开源矩阵里已有 20 个仓库，但全是**结论态**——想清楚了才发。没有一样记录「还没想清楚时的挣扎痕迹」。

而恰恰是后者对读者价值最高（能看到真实的爬坡曲线），对作品集也最稀缺（成品人人有，爬坡证据没人有）。

| 仓库 | 时态 | 回答什么 |
|------|------|----------|
| [xingtu-ai-engineering](https://github.com/xingtu1996/xingtu-ai-engineering) | 完成时 · 结论态 | What to do（该怎么做） |
| **xingtu-learn（本仓）** | **进行时 · 过程态** | **How I got there（我是怎么走到这的）** |

两者不打架，是上下游：**在这里长熟、被验证的方法，蒸馏进 ai-engineering；不成熟的留在这里，不污染成品仓。**

## 学习地图（三轴）

| 轴 | 驱动源 | 线 | 状态 | 目录 |
|----|--------|----|------|------|
| **轴 A · 技术** | 兴趣与趋势 | Agent 全景（上下文 → 提示词 → 工具 → 循环） | 活跃 · 刚起步 | [`10-tech/agent-from-scratch/`](10-tech/agent-from-scratch/) |
| **轴 B · 考证** | 考试 | 软考高项（信息系统项目管理师）2027 | 进行中 · 周打卡 | [`20-cert/软考高项-2027/`](20-cert/软考高项-2027/) |
| **轴 B · 考证** | 考试 | PMP 2023（已考，回溯复盘） | 归档 · 记忆重建 | [`20-cert/pmp-2023/`](20-cert/pmp-2023/) |
| **轴 C · 工作驱动** | **项目倒逼** | 多租户配置治理 | 学习中 | [`40-work-driven/`](40-work-driven/) |

**轴 C 是完成率最高的一条。** 原因很朴素：自驱学习靠意志力，工作驱动靠 deadline——前者会耗尽，后者不会。

工作驱动的完整说明见 [`40-work-driven/README.md`](40-work-driven/)。简单说它的结构是：

```
做了什么项目 → 遇见什么障碍 → 需要学什么 → 学了什么 → 回到工作怎么用的
```

最后一段是关键。缺了"回到工作"，它就退化成了普通笔记。

对应的项目侧记录在 [xingtu-portfolio](https://github.com/xingtu1996/xingtu-portfolio)——那边记"我当时为什么这么选"，这边记"这个项目逼我学了什么"，两个仓互相喂料。

方法沉淀（本仓真正的长期资产）在 [`00-method/`](00-method/)——笔记会过时，方法不会。

## 三条自律（写给自己，欢迎监督）

1. **每条记录必带 status**：`活跃` / `归档` / `已过时`。AI 领域半年就过时，诚实标注过时比装作没写过更有信任价值——这也是作品集的一部分：你知道自己在什么时候错了。
2. **每条记录必回答「读者能拿走什么」**，写在文件开头。答不上来的不提交。
3. **每周至少 1 次 commit**，哪怕只是周日志。死掉的仓库不是因为内容差，是因为断更。

## 红线自律（公开仓库的自我约束）

这个仓是公开的，所以有些东西**永远不会出现在这里**：

- **不搬运他人版权内容**：培训讲义、教材扫描件、题库真题，一律不入库。讲者观点一律转述并注明出处，不整段复制。
- **不放个人信息**：真实姓名、联系方式、雇主与职级。涉及工作经历的案例一律泛化。
- **不碰公司资产**：内部代码、架构、数据绝不进公网仓库（SAF-006）。

想看原始素材和未消化的流水？那些留在本私有工作区，不公开。**分层公开**——既真实，又不裸奔。

## 怎么用

### 想跟着学
从 [`10-tech/agent-from-scratch/README.md`](10-tech/agent-from-scratch/) 开始，那是最完整的一条线。

### 想照着建自己的学习仓
复制 [`templates/`](templates/) 下的模板，改个名字就能用：

```bash
git clone https://github.com/xingtu1996/xingtu-learn.git
cp -r xingtu-learn/templates/ ./my-learning-log
```

欢迎 fork。**如果对你有用，给个 star 就是对我继续公开的最大支持。**
